# Reimagined Level Editor icon

Generated using the built-in image generation tool, with `reimagined-launcher/ReimaginedLauncher/Assets/ReimaginedLauncher.png` as visual inspiration. The final PNG is `ReimaginedLevelEditor.png`; `scripts/Build-Icon.ps1` packages 16, 24, 32, 48, 64, 128 and 256 pixel PNG frames into `ReimaginedLevelEditor.ico`. The final design intentionally uses an opaque charcoal background.

Initial prompt:

> Create a square Windows application icon for Reimagined Level Editor. Reference image is style inspiration only: black forged metal, sharp crimson edges, gothic dark fantasy. Create a distinct bold emblem combining an isometric three-tile map platform with a small angular red horned crest above it. No letters or text. Strong readable silhouette at 32 pixels, restrained silver highlights, crimson red accents, transparent background. Centered with generous safe padding. Polished game tool icon, not a scene.

Final revision prompt:

> Keep this red and black horned map-tile emblem. Replace the entire gray checkerboard with a perfectly solid charcoal black #141B23 background. No checkerboard anywhere. Scale emblem down slightly to leave 10 percent safe padding at all edges. Square desktop application icon, no text, crisp strong silhouette. Opaque background intentional.
